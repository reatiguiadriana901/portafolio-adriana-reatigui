AS_TechShop

Base de datos y analítica para una tienda en línea de tecnología

Database and analytics for an online technology store

AS_TechShop es una base de datos relacional en MySQL 8 para una tienda de tecnología. Gestiona catálogo, inventario, clientes y ventas, e incluye consultas analíticas, lógica en el servidor y un esquema de seguridad por roles.

AS_TechShop is a relational MySQL 8 database for a technology store. It manages the catalog, inventory, customers and sales, and includes analytical queries, server-side logic and role-based security.

Qué haceWhat it does

  • Consultas con CTE y funciones de ventana como PERCENT_RANK y LAG.
  • Procedimientos transaccionales para registrar ventas, procesar devoluciones y ajustar el stock.
  • Triggers que auditan cambios de precio, impiden stock negativo y recalculan el total de una venta.
  • Eventos programados para reportes, limpieza de tablas temporales y lista de reabastecimiento.
  • Permisos por columna, por ejemplo un rol de inventario que solo puede actualizar stock y ubicación.
  • Queries with CTEs and window functions such as PERCENT_RANK and LAG.
  • Transactional procedures to register sales, process returns and adjust stock.
  • Triggers that audit price changes, prevent negative stock and recalculate a sale's total.
  • Scheduled events for reports, temporary table cleanup and a restock list.
  • Column-level permissions, for example an inventory role that can only update stock and location.
