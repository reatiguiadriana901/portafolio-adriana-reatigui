Proyecto con python

Mi primer proyecto completo usando python fue una aplicación de consola que permite registrar, listar y analizar gastos personales. Permite filtrar por categoría y fechas, calcular totales diarios, semanales y mensuales, y generar reportes en pantalla o en formato JSON. Los datos se almacenan en un archivo JSON para mantener el historial entre sesiones

Lo que aprendí:

  • Filtrado y procesamiento de datos por categoría y fechas
  • Cálculo de totales y generación de reportes
  • Programación modular y organización de funciones

Automatización + IA

TalentFlow AI

Plataforma de automatización para la recepción, evaluación con IA (Google Gemini) y gestión centralizada de postulaciones laborales. El sistema valida duplicados, extrae texto de hojas de vida en PDF, evalúa la compatibilidad del candidato frente a las vacantes, registra métricas en PostgreSQL y Google Sheets, y notifica a RRHH vía Gmail y Telegram.

Lo que aprendí:

  • Automatización de flujos con n8n (webhooks, agentes IA, ruteo condicional)
  • Integración con Google Gemini para evaluar candidatos
  • Extracción de texto de PDF y validación de duplicados
  • Gestión de datos en PostgreSQL y Google Sheets
  • Notificaciones vía Gmail OAuth2 y Telegram Bot API
